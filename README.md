# Emotion Detection Application

## Project Description
This project uses IBM Watson Natural Language Processing (NLP) to detect emotions expressed in text.

## Features
- Detects anger, disgust, fear, joy, and sadness.
- Returns emotion scores and identifies the dominant emotion.
- Provides a Flask web interface.
- Handles invalid or empty input.
- Includes unit tests and static code analysis.

## Technologies
- Python
- IBM Watson NLP
- Flask
- Unittest
- PyLint
